# Validation scope

`public-tests.txt`, `public-lint.txt`, and `public-build.json` are generated by `tools/build_release.py` from actual local execution.

The tests run the real Home Assistant test runtime with external sockets disabled. They cover exact-model selection, OAuth state/expiry/reauth flow using synthetic credentials, readable decoding, duplicate suppression, observation persistence, setup/unload/removal, transport parsing with synthetic MQTT messages, HTTP request construction with mocked responses, and HACS package metadata.

Synthetic fingerprint and palm-code regression tests verify decoder behaviour, not live biometric recognition. The source meaning of the normal fingerprint event was separately corroborated against a user-operated event received through an existing integration. No private device identifiers, credential IDs, household timestamps, raw histories, or biometric payloads are published.

Not yet verified: live OAuth authorization and MQTT delivery through this standalone integration, installation into live HA, palm-vein event-code mapping, cloud reliability, physical-use latency, or migration of existing automations. No lock operation is performed by a test.

The repository is packaged for HACS custom-repository installation, not approved for the default catalogue. The retained upstream license is non-OSI and must not be relabelled merely to pass a catalogue license check.
